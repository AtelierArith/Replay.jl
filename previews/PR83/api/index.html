Replay.replay — Function
replay(instructions::Vector{<:AbstractString}, buf::IO; kwargs...)

Replay the REPL output from given instructions.

Keyword Arguments

Replay options

  • use_ghostwriter: Flag to enable ghostwriter mode. (default: false)

  • startup_prompt: Text to wait for when the child REPL starts. (default: "julia>")

  • prompt_delimiter: Text ending each subsequent prompt. (default: "> ") For numbered prompts use startup_prompt="In [1]: ", prompt_delimiter="]: ", and leave use_ghostwriter=false; ghostwriter assumes the standard prompts.

Julia options

  • julia_project: Path to a project where julia process runs. (default: @.)
  • cmd: Additional command for julia process. (default: "--color=yes")

Numbered prompts

Initialize Julia's REPL interface before enabling numbered prompts:

replay(["1 + 1", "ans * 2"];
    cmd=`-q --color=no -e 'using REPL; atreplinit(repl -> (repl.interface = REPL.setup_interface(repl); REPL.numbered_prompt!(repl)))'`,
    startup_prompt="In [1]: ", prompt_delimiter="]: ")

Interactive menus

ASCII REPL.TerminalMenus menus can be replayed with the default prompt delimiter. Put the request and its response in separate instructions and use a carriage return ("\r") to confirm a selection:

replay([
    "using REPL.TerminalMenus",
    "menu = RadioMenu(["apple", "orange"]);",
    "choice = request("Choose fruit:", menu)",
    "$(DOWN_ARROW)\r",
    "@show choice",
])

Use "q" to cancel a TerminalMenus request. Menu requests must display the configured prompt_delimiter; arbitrary full-screen TUIs or menus with different cursor styles are not automatically detected. Keep use_ghostwriter=false for raw menu keystrokes.

Replay.@deparse — Macro
@deparse expr

Create a string from expr. It tries to output something similar to we type in Julia REPL. If expr contains @comment <message>, it is transformed into # <message>.

Examples

julia> @deparse 1+1
"1 + 1"

julia> @deparse sin(1f0+a)
"sin(1.0f0 + a)"

julia> @deparse f(x) = sin(x)/x  # Sometimes not work as expected
"f(x) = begin\n        sin(x) / x\n    end\n"
